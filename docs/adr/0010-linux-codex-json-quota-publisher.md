# 增加直接读取 CPA Codex JSON 的 Linux 后台服务

Linux 可执行文件由 systemd 管理，直接读取用户放入固定认证目录的单个 CPA Codex 登录 JSON，不启动或监控 CPA 服务。服务按计划查询 Codex 用量和 Codex Resets 状态，复用现有渲染器生成图片，并在画面变化时推送到 NOTE4。设备显示会被新画面替换；本地不保存图片历史。

额度默认每十分钟读取一次，重置雷达默认每小时读取一次。普通 OAuth 与 SIWC token 到期前会刷新；用量接口返回 401 时也会刷新并重试。上游轮换后的令牌先写入 `CODEX_ZECTRIX_DATA_DIR/codex-auth.cache`，额度成功解析后再同步到本机加密凭证文件。首次成功取得并解析额度后，服务保留未知 JSON 字段，并以 AES-256-GCM 密文原子替换原 JSON 文件。密文仍使用原文件名和目录。未能成功解析额度时，源文件保持原样。运行账户必须能写入认证目录。

凭证文件及数据目录中的缓存使用同一加密密钥。服务从 `CACHE_ENCRYPTION_KEY_FILE` 读取 32 字节密钥，并结合宿主机 `/etc/machine-id` 派生 AES-256-GCM 密钥；复制到另一台 machine-id 不同的主机后不能解密。密文不能代替备份：若主机标识或密钥丢失，应放入新的 CPA 导出 JSON 重新初始化。原子替换会移除目录中的明文文件内容，但不能保证擦除 SSD、快照或日志文件系统中已释放的数据块。

Codex 用量路由是 ChatGPT 内部接口，没有公开的兼容性承诺。接口拒绝请求或响应格式变化时，服务保留上次有效的加密额度并标记为过期；重置雷达失败时按现有有效期显示缓存状态。
