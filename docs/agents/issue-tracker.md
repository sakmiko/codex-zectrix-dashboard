# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, comment on, label, and close issues with `gh issue`.
- Infer the repository from `git remote -v`.
- Pull requests are not treated as incoming requests for triage.
- When a skill says “publish to the issue tracker,” create a GitHub issue.
- When a skill says “fetch the relevant ticket,” read the issue and its comments.
- `/wayfinder` uses a map issue, linked child issues, and native GitHub issue dependencies where available.
