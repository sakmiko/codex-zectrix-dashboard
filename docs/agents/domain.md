# Domain Docs

Before exploring the codebase, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist. Missing files should not be created pre-emptively; `/domain-modeling` creates them when terminology or decisions are actually resolved.

This is a single-context repository:

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

Use terminology defined in `CONTEXT.md`. Explicitly flag any proposal that conflicts with an existing ADR.
