# 直接读取公开重置雷达 API

Linux 后台服务通过独立 HTTP 客户端读取 Codex Resets 公开状态 API。服务启动时立即请求，之后默认每小时请求一次；ETag、超时、响应大小限制和语义缓存将此可选来源与 Codex 官方额度查询隔离。

只解析看板需要的预测窗口、可选概率和重置确认字段。服务不保存完整上游响应，不把网络错误推断为“没有预测”。请求失败时，只在现有有效期内继续显示已验证的预测或确认；重启后必须重新取得有效的“暂无预测”结果。

上游 endpoint 固定为 `https://codex-resets.com/api/v1/status`。更换来源需要审查解析与有效期规则。概率和预测窗口按上游有效字段显示，不解释为账户专属重置承诺。
